# HawkerLens SG 🔍🍗

Snap your hawker lunch, know your lunch. Hawker-food nutrition with Singlish soul.

Built for **Build With AI: Basics** (Devpost) using the Learn Skill Pack: `scope → prd → spec → build`. Planning docs in [`devpost/`](devpost/).

## Try it
Open `index.html` in a browser. No install, no keys, works offline.

Or serve: `python3 -m http.server` → http://localhost:8000

## What it does
- 📸 Snap/upload dish photo (stays on device)
- 🍜 12 real SG hawker dishes with kcal, macros, allergens
- 💪 Healthier swap for every dish + kcal saved
- 🌶 Spice level, EN/简体 toggle, search filter
- 💾 Remembers last dish + language (localStorage)

## Dish data
Estimates from HPB averages — not medical advice. See `data/dishes.json`.
